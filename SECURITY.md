# Security policy

## Supported version

Security fixes are applied to the current `main` branch.

## Reporting a vulnerability

Please do not include credentials, personal information, exploit payloads, or other sensitive material in a public issue. Use GitHub private vulnerability reporting when it is enabled for this repository. Otherwise, open a minimal issue requesting a private contact channel without disclosing the vulnerability details.

INQUISITION is a static client application. It does not require accounts, passwords, API keys, analytics identifiers, cookies, or a backend service.
